# compas_table

Работа с таблицами в чертежах КОМПАС-3D через COM-API.

## Описание

Проект содержит два скрипта для автоматизации работы с таблицами в КОМПАС-3D:

- **`example_read.py`** — чтение данных из таблиц и текстовых объектов активного чертежа КОМПАС-3D. Последовательно перебирает все текстовые объекты на чертеже, затем находит все таблицы и выводит содержимое их ячеек тремя способами: через Range, по ID ячейки и через Text(row, col).

- **`compas_create_table.py`** — создание таблицы в активном чертеже КОМПАС-3D на основе данных из XLSX-файла. Читает Excel-файл (`loodsman_report_ko_101388.xlsx`), формирует таблицу с заголовками (Наименование детали, Количество на изделие, Обозначение детали, Наименование материала, Марка материала) и размещает её на текущем виде чертежа.

## Требования

- КОМПАС-3D (API 7)
- Python 3.x
- `pywin32` (win32com)
- `openpyxl` (только для `compas_create_table.py`)

Установка зависимостей:

```bash
pip install pywin32 openpyxl
```

## Использование

1. Откройте чертёж в КОМПАС-3D.
2. Запустите нужный скрипт:

```bash
python example_read.py
python compas_create_table.py
```

Для `compas_create_table.py` файл `loodsman_report_ko_101388.xlsx` должен находиться в рабочей директории (откуда запускается скрипт).
